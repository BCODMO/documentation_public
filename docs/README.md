# BCO-DMO "How To?" Pages

Welcome to the BCO-DMO "How To?" Pages. We understand that the world of data management and organization, repositories, project requirements and navigating BCO-DMO specifically can be challenging.&#x20;

Therefore we created these public how to pages. Each page uses a step-by-step approach to show you how to perform certain data tasks that working with BCO-DMO requires. From data planning, submitting data and reusing the data. As well as explanations on how our data package looks like and extra educational sources on data science.

We hope you enjoy these walkthroughs, but if there is anything that you can't find or if you still have questions, shoot us an email at info\[AT]bco-dmo.org
