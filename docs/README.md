# BCO-DMO Guide

Welcome to the BCO-DMO Guide. We understand that navigating the many aspects of the data world and BCO-DMO can be challenging. This guide is here to help you find your way through it all.&#x20;

These pages offer a step-by-step approach explaining how to perform certain BCO-DMO data tasks such as [data planning](prepare/data_management_plan.md), [submitting new data](contribute/#the-submission-process-step-by-step), and [reusing existing data](access-and-reuse/). This guide also provides information about such things as what our data packages include and links to [educational sources](education-and-training/) on data science.

**Please note that this guide is still under construction** so you may find some blank pages but we are continually working to expand the information available here. Check back for updates or reach out if you have questions.

We hope you find this guide helpful, but if there is anything you can't find or if you still have questions, shoot us an email at [info@bco-dmo.org](mailto:info@bco-dmo.org).

-The BCO-DMO Team&#x20;
