# Welcome!

Welcome to the BCO-DMO "How To?" Pages. We understand that the world of data management and organization, repositories, project requirements and navigating BCO-DMO specifically can be challenging.&#x20;

Therefore we created these public how to pages. Each page uses a step-by-step approach to show you how to perform certain data tasks that working with BCO-DMO requires. From [data planning](data-planning/), [submitting data](submit-data/) and [reusing the data](access-and-reuse-data/). As well as explanations on how our [data package](01\_access\_dataset/) looks like and [extra educational sources](education/) on data science.

We hope you enjoy these walkthroughs, but if there is anything that you can't find or if you still have questions, shoot us an email at info\[AT]bco-dmo.org
