# Welcome!

Welcome to the BCO-DMO "How To?" pages. We understand that navigating the many aspects of the data world and BCO-DMO can be challenging. These pages are here to help you find your way through it all.&#x20;

Each page uses a step-by-step approach to show you how to perform certain BCO-DMO data tasks such as [data planning](data-planning/), [submitting data](submit-data/) and [reusing the data](access-and-reuse-data/). As well as explanations on how our [data package](data-package/) looks like and [extra educational sources](education/) on data science.

We hope you enjoy our digital walk-throughs, but if there is anything that you can't find or if you still have questions, shoot us an email at info\[AT]bco-dmo.org
