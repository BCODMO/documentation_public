# Welcome!

Welcome to the BCO-DMO "How To?" pages. We understand that navigating the many aspects of the data world and BCO-DMO can be challenging. These pages are here to help you find your way through it all.&#x20;

**Please note that this guide is still under construction** so you may find some blank pages but we are continually working to expand the information available here, so check back for updates or reach out if you have questions.

Each page uses a step-by-step approach to show you how to perform certain BCO-DMO data tasks such as [data planning](data-planning/), [submitting new data](data-submission/), and [reusing existing data](access-and-reuse-data/). This guide also provides information about such things as what our data packages include and links to [educational sources](education/) on data science.

We hope you enjoy our digital walk-throughs, but if there is anything that you can't find or if you still have questions, shoot us an email at [info@bco-dmo.org](mailto:info@bco-dmo.org).

The BCO-DMO Team&#x20;
