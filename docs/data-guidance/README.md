Topic Specific Data Guidance



Please make sure to have prepared the following:

1. **Descriptive Metadata:** A dataset needs to be accompanied by [**metadata**](../contribute/metadata-for-datasets/) for new users to be able to understand and reuse the datasets we hold.&#x20;
2. **Data Files:** The **organization of the data** could vary depending on the data type. There is a distinction between [data tables](organizing-data-tables.md), [genetic accessions](genetic-accessions.md), and [Models & Code](software-and-code.md). We also have specific guidance for certain research programs or projects, such as [GEOTRACES](../contribute/metadata-for-datasets/geotraces.md).
