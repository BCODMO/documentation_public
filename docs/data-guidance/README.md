# Prepare

## Planning your Project with a Data Management Plan

Open access data, one of the outputs of a research project, starts with a plan, more specifically a Data Management Plan. Think about all the steps in the [data life cycle](../education-and-training/the-data-life-cycle.md) and data needs at each step such as: data types that will be gathered, file formats of those data, naming conventions, metadata formats, repositories that will be used for data sharing, and plans for long-term archive.&#x20;

The [Data Management Plan page](../data-planning/data\_management\_plan.md) has in depth description of such plan as well as the NSF requirements and BCO-DMO template on the DMP tool.&#x20;

## General Guidance for BCO-DMO Datasets

A dataset submitted to BCO-DMO needs **sufficient quality to validate and replicate research findings.**&#x20;

**Descriptive Metadata**: Each dataset needs information providing sufficient context for peer review and reuse of the data. Therefore, each dataset has its own metadata page, describing the who/what/where/how information about the data. See full details of necessary metadata [here](../contribute/metadata-for-datasets/).&#x20;

## Data Type Specific Guidance

The organization of your data can vary depending on the data type. There is a distinction between [data tables](organizing-data-tables.md), [genetic accessions](genetic-accessions.md), and [Models & Code](software-and-code.md). We also have specific guidance for certain research programs or projects, such as [GEOTRACES](../contribute/metadata-for-datasets/geotraces.md).
