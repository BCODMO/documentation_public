# Flow Cytometry (FCM) Data

Are you planning to contribute Flow Cytometry (FCM) data to BCO-DMO? Here are some community-generated best practice recommendations to consider when preparing your data for submission based on Ribalet et al. (2023), doi: [10.5281/zenodo.8329545](https://doi.org/10.5281/zenodo.8329545). \
\
We often receive data tables that include cell counts, features, biomass, identifications, etc. from FCM analysis. In addition to any data tables, we encourage you to also submit the raw .fcs files [Flow Cytometry Standard (FCS)](https://isac-net.org/page/Data-Standards), which we can attach as supplemental files to your dataset page.

{% hint style="warning" %}
**Include Flow Cytometry Standard (FCS) files where possible**\
\
FCS is a data file standard for the reading and writing of data from flow cytometry experiments. These files have been identified as important for data reuse. The FCS specification has traditionally been developed and maintained by the International Society for Advancement of Cytometry (ISAC).
{% endhint %}
