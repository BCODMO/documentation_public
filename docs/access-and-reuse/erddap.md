# ERDDAP

BCO-DMO has adopted ERDDAP to provide a simple, consistent way to access and download datasets in several common file formats (e.g, CSV, NetCDF, or JSON), with the capability of creating graphs and maps. ERDDAP's web services can be used in several different applications and utilities such as Python, R, Javascript, and MATLAB.

BCO-DMO has its own ERDDAP server. While all of our datasets can be found in our data explorer, not all datasets have been transferred to the [**BCO-DMO ERDDAP server**](https://erddap.bco-dmo.org/erddap/index.html), but we are continuously working to do so.&#x20;

![BCO-DMO ERDDAP server](<../.gitbook/assets/image (38).png>)

All information about every ERDAPP request is contained in the URL of each request, which makes it easy to automate searching for and using data in other applications. Many organizations (including NOAA, NASA, and USGS) run ERDDAP servers to serve their data. Because of its widespread use and accessibility, the ERDDAP principal developer and user community have created **user guides**, [**instruction videos**](https://youtu.be/RPIM5nFlNNY), and code examples to facilitate access by new users.
