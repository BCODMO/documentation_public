# Data Package

From the data display: Click on blue links to drill down into the data or click on the 'Next Level' button to see all the data at the next level.  Click the 'Flat Listing' after there are no more hyperlinks to get all the data.  At this point, you can copy and paste the data into an Excel or text file. You can see an alternate view of publicly accessible metadata by clicking on the Documentation link at the top of the data display page.
